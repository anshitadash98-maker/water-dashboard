# India Water Watch

An interactive dashboard that visualizes water resource data across India — availability, consumption, and groundwater trends by region.

Live: [Add your GitHub Pages link here]

## About

A simple, animated web page that turns water resource data into charts you can actually scroll through and understand. Built with plain HTML, CSS, and JavaScript, no frameworks involved.

## Features

- Interactive charts using Chart.js and amCharts
- Scroll-triggered water animations
- Responsive layout for desktop and mobile
- Region-wise data comparison

## Tech Stack

- HTML5
- CSS3 for styling and animations
- Vanilla JavaScript
- Chart.js and amCharts for data visualization
- Hosted on GitHub Pages

## Getting Started

git clone https://github.com/anshitadash98-maker/<repo-name>.git
cd <repo-name>

No build step or dependencies needed. Just open index.html in a browser, or run a local server:

npx serve .
